= Agregar un sistema de Google Cloud NetApp Volumes
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Después de configurar una cuenta de servicio, agregue un sistema Google Cloud NetApp Volumes en la NetApp Console para poder ver sus instancias de Google Cloud NetApp Volumes .

Los volúmenes de nube para esta suscripción se muestran en el sistema.


NOTE: Si tiene suscripciones y volúmenes en varios proyectos de Google Cloud, deberá realizar esta tarea para cada proyecto.

.Antes de empezar
Antes de añadir un sistema para cada proyecto, asegúrate de que:

* La cuenta de servicio de Google Cloud está configurada y sus credenciales están disponibles en la NetApp Console. Para obtener más información, consulta link:task-set-up-gcnv.html["Configurar Google Cloud NetApp Volumes"].
* Tienes el rol de administrador o visor de Google Cloud NetApp Volumes en NetApp Console. Para obtener más detalles, consulta link:task-add-roles.html["Asignar roles de Google Cloud NetApp Volumes"].


.Pasos
. Desde el menú de la NetApp Console , seleccione *Almacenamiento* y luego *Administración*.
. En la página Sistemas, seleccione *Agregar sistema* y seleccione *Google Cloud Platform*.
. Junto a * Google Cloud NetApp Volumes*, seleccione *Descubrir*.
. Proporcione información sobre su suscripción a NetApp Volumes:
+
.. Introduzca el nombre del sistema que desea utilizar.
.. En *Credenciales*, selecciona las credenciales de Google Cloud NetApp Volumes que desees utilizar.
+
Si no aparece ninguna credencial, añade las credenciales de Google Cloud NetApp Volumes antes de continuar. La selección del proyecto y la región no estarán disponibles hasta que haya credenciales.

.. En «*Region*», selecciona una región compatible para Google Cloud NetApp Volumes.
.. Seleccione *Descubrir*.




.Resultado
La consola muestra su sistema Google Cloud NetApp Volumes .
