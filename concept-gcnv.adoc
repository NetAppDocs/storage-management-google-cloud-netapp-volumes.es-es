= Obtenga más información sobre Google Cloud NetApp Volumes
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Google Cloud NetApp Volumes es un servicio de almacenamiento de datos basado en la nube totalmente administrado que brinda capacidades avanzadas de administración de datos y un rendimiento altamente escalable.

NetApp Volumes ayuda a acelerar los tiempos de implementación, administrar sus cargas de trabajo y aplicaciones, y migrar cargas de trabajo a la nube manteniendo el rendimiento y las características del almacenamiento local.


NOTE: Para comenzar a trabajar con Google Cloud NetApp Volumes, debe tener los permisos adecuados y el rol de administrador de Google Cloud NetApp Volumes o de visor de Google Cloud NetApp asignado. link:task-add-roles.html["Asignar roles de acceso para volúmenes de NetApp"^].

image:role_gcnv.png["Una captura de pantalla de la función Google Cloud NetApp Volumes ."]



[[features]]
== Funciones

* Ejecuta aplicaciones empresariales de forma más rápida y eficiente.
* Reduce los costos de almacenamiento en la nube hasta en un 90%.
* Cumple con los mandatos de tiempo de actividad, disponibilidad y seguridad.
* Admite entornos NFS, SMB y multiprotocolo.




[[cost]]
== Costo

Los volúmenes creados por Google Cloud NetApp Volumes se cargan a su suscripción al servicio, no a través de la NetApp Console.

No hay ningún cargo para descubrir una región o un volumen de Google Cloud NetApp Volumes desde la NetApp Console.

[[getting-help]]
== Obtener ayuda

Para obtener asistencia técnica, registre una solicitud a través del portal de Google Cloud.  Elija su suscripción a Google Cloud y el servicio * Google Cloud NetApp Volumes* en *Almacenamiento*.  Complete la información requerida.

Para preguntas generales sobre Google Cloud NetApp Volumes, envíe un correo electrónico al equipo de Google Cloud de NetApp a gcinfo@netapp.com.

Para problemas técnicos asociados con sus volúmenes en la nube, puede crear un caso de soporte técnico desde Google Cloud Console. Verlink:https://cloud.google.com/netapp/volumes/docs/support["obtener apoyo"^] Para más detalles.
