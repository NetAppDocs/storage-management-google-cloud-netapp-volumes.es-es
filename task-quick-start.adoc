= Flujo de trabajo de introducción
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Comience a utilizar Google Cloud NetApp Volumes configurando Google Cloud y luego creando un sistema.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"] link:task-set-up-gcnv.html["Configurar Google Cloud NetApp Volumes"]
[role="quick-margin-para"]
Desde Google, crea una cuenta de servicio.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dos"] link:task-add-roles.html["Asignar roles"]
[role="quick-margin-para"]
Desde la NetApp Console, asigne los roles correctos a los miembros.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tres"] link:task-create-system.html["Agregar un sistema"]
[role="quick-margin-para"]
Desde la NetApp Console, haga clic en *Agregar sistema*, luego en *Google Cloud Platform*, luego en * Google Cloud NetApp Volumes* y luego en *Descubrir*.  Proporcione los detalles sobre la cuenta de servicio y el proyecto de Google Cloud.
