= Inicio rápido para Google Cloud NetApp Volumes
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Empieza con Google Cloud NetApp Volumes asignando tu rol de NetApp Console, añadiendo credenciales y detectando un sistema.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"] link:task-add-roles.html["Asignar roles"]
[role="quick-margin-para"]
Desde la NetApp Console, asigne los roles correctos a los miembros.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dos"] link:https://docs.netapp.com/us-en/data-services-workloads/gcnv/add-credentials.html["Añade credenciales"]
[role="quick-margin-para"]
En NetApp Console, añade las credenciales de Google Cloud NetApp Volumes.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tres"] link:task-create-system.html["Agregar un sistema"]
[role="quick-margin-para"]
En la NetApp Console, descubre un sistema con las credenciales, el proyecto de Google Cloud y la región compatible.
